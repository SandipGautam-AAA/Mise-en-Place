# 🍳 Mise-en-Place
### "Everything in its Place" | My First Game Development Project

Welcome to **Mise-en-Place**. This repository marks my transition from academic exercises to building a structured game development workflow. Named after the culinary practice of preparing ingredients before cooking, this project focuses on organized architecture and fundamental **Unreal Engine** systems.

## 🧠 What I Have Learned
This project has been a significant milestone in my journey. Here is a breakdown of the core competencies I've developed:

### 🎮 1. Enhanced Input System (UE5)
I moved beyond legacy input systems to master the **Enhanced Input** framework. 
* **Mapping Contexts:** Learned how to swap controls dynamically based on player state.
* **Input Actions:** Created modular triggers for movement, sprint, and crouch.
- *This ensures the project is scalable for complex mechanics later on.*

### 🛠 2. Professional Version Control
A major part of this project was mastering Git as a tool, not just a backup.
* **History Management:** Learned how to "Mise-en-Place" a repo by wiping outdated history to start fresh.
* **Efficiency:** Implementing a robust `.gitignore` to handle large Unreal Engine binaries, keeping the repository lightweight.
* **Rebase & Sync:** Managing conflicts and syncing local work with GitHub seamlessly.
